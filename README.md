# YouTube to MP3

이 컴퓨터에서 `YouTube to MP3.cmd`를 더블클릭하거나 Windows 시작 메뉴의 `YouTube to MP3` 바로가기로 실행합니다. 현재 설치된 `C:\Python314\pythonw.exe`를 사용하며 별도 서버와 계정은 필요하지 않습니다.

1. 유튜브 동영상 또는 재생목록 주소를 붙여넣습니다.
2. **한 곡만 다운로드** 또는 **재생목록 전체**를 선택합니다.
3. 저장 폴더를 선택하고 **MP3 다운로드**를 누릅니다.

한 곡 모드는 주소에 재생목록 정보가 있어도 해당 동영상만 받습니다. 전체 모드는 재생목록을 처음부터 받으며, 재생목록 이름의 하위 폴더에 순번을 붙여 저장합니다. 같은 이름의 기존 MP3가 있으면 오디오 다운로드와 재인코딩을 건너뛰고 표지·태그를 갱신합니다. 기본 저장 폴더는 Windows 다운로드 폴더 `C:\Users\PC\Downloads`입니다.

최고 원본 오디오를 선택해 MP3 320kbps로 변환합니다. 유튜브 원본은 이미 압축된 오디오이므로 320kbps 변환이 원본 이상의 음질이나 무손실 음질을 만들지는 않습니다. 변환까지 끝나고 MP3 파일이 존재하는 항목을 저장 확인 수에 집계합니다. 기존 MP3를 재사용한 항목도 포함될 수 있습니다.

유튜브 썸네일을 MP3의 대표 표지로 내장하고, 제공되는 제목·음악가·앨범 정보를 ID3 태그에 저장합니다. 음악가 정보가 없는 일반 영상은 업로더 정보를 사용하며, 제공되지 않은 앨범명은 임의로 만들지 않습니다. 예전에 받은 파일에 추가하려면 같은 저장 폴더에서 같은 주소와 다운로드 모드로 다시 실행하세요. 기존 MP3를 다른 프로그램에서 사용 중이라 태그 갱신이 실패하면 해당 프로그램을 닫고 다시 시도하세요. 새 파일은 임시 폴더에서 표지·태그 처리를 마친 뒤 최종 폴더로 이동합니다.

앱 자체에 광고, 결제, 하루 다운로드 제한을 넣지 않았습니다. 유튜브의 비공개·삭제·지역·로그인 제한이나 요청 제한은 다운로드에 영향을 줄 수 있습니다. 실패 내역은 화면 기록에 표시하며, 일부 곡이 실패해도 다음 곡을 계속 처리합니다. 라이브 방송과 자동 생성 믹스처럼 끝이 정해지지 않은 주소보다 일반 동영상·고정 재생목록을 사용하세요.

첫 실행에는 인터넷을 통해 공식 GitHub에서 yt-dlp, FFmpeg, Deno를 `tools`에 설치합니다. SHA256 검사 후 사용하며 시스템 PATH와 브라우저 설정은 변경하지 않습니다. 사이트 변경으로 다운로드가 실패하면 **다운로드 도구 업데이트**를 실행할 수 있습니다. 중지는 현재 작업과 변환 자식 프로세스를 종료하며, 완료된 MP3는 유지합니다. 미완료 파일은 남을 수 있습니다.

소스: https://github.com/yt-dlp/yt-dlp · https://github.com/yt-dlp/FFmpeg-Builds · https://github.com/denoland/deno

변환 임시 파일은 저장 폴더의 `.goyo-partials` 아래에서 처리하며, 변환이 끝난 MP3만 최종 폴더로 이동합니다. 중지 후 다시 시작하면 완료된 파일은 유지하고 미완료 곡은 새 임시 경로에서 다시 처리합니다. 중지된 임시 파일은 자동 삭제하지 않습니다.

다른 PC에서는 Python과 Tk가 필요하며 실행 파일의 Python 경로를 해당 설치 위치로 변경해야 합니다.
