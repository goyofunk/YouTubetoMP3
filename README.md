# YouTube to MP3

- `YouTube to MP3.cmd` 또는 시작 메뉴 바로가기로 실행 (`C:\Python314\pythonw.exe` 사용, 서버·계정 불필요)
- 유튜브 주소 입력 후 **한 곡 모드** 또는 **재생목록 전체** 선택 및 저장 폴더 지정 후 다운로드 실행
- 한 곡 모드는 재생목록 주소여도 해당 영상만 다운로드, 전체 모드는 재생목록 하위 폴더에 순번을 붙여 저장
- 동일한 이름의 기존 MP3 존재 시 다운로드와 재인코딩을 건너뛰고 표지 및 태그만 갱신 (기본 저장 폴더: `C:\Users\PC\Downloads`)
- 최고 원본 오디오를 MP3 320kbps로 변환 후 성공 항목(재사용 포함) 저장 확인 수 집계
- 유튜브 썸네일 표지 내장 및 ID3 태그(제목, 음악가/업로더, 앨범) 저장 (임의의 앨범명 미생성)
- 동일 저장 폴더에서 같은 주소와 모드로 재실행 시 기존 파일에 태그 추가 가능 (파일 사용 중인 타 프로그램 종료 후 재시도)
- 새 파일은 임시 폴더(`.goyo-partials`)에서 처리 완료 후 최종 폴더로 이동
- 광고, 결제, 하루 다운로드 제한 없음 (비상업적 목적의 무료 도구)
- 라이브 방송 및 자동 생성 믹스 대신 일반 동영상 및 고정 재생목록 권장
- 첫 실행 시 공식 GitHub에서 yt-dlp, FFmpeg, Deno를 `tools`에 자동 설치 및 SHA256 검증 (시스템 PATH·브라우저 미변경)
- 사이트 변경 대응을 위한 **다운로드 도구 업데이트** 기능 제공
- 중지 시 현재 작업 및 자식 프로세스 종료 (완료된 MP3는 유지, 미완료 파일 및 중지된 임시 파일은 잔존)
- 소스 및 오픈소스 출처: [yt-dlp](https://github.com/yt-dlp/yt-dlp) (Unlicense) · [FFmpeg-Builds](https://github.com/yt-dlp/FFmpeg-Builds) (GPL-3.0) · [Deno](https://github.com/denoland/deno) (MIT)
- 다른 PC 실행 시 Python과 Tk 필요 및 실행 파일의 Python 경로 수정 필요
