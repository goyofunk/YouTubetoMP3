# YouTube to MP3

유튜브 주소를 입력하면 MP3 파일로 저장하는 Windows 데스크톱 프로그램입니다. 한 곡 또는 재생목록 전체를 선택할 수 있으며 광고·결제·하루 다운로드 제한이 없습니다.

![YouTube to MP3 프로그램 화면](.github/thumb.png)

## 설치와 실행

1. 배포받은 `YouTube-to-MP3-1.0.0-Setup.exe`를 실행하고 설치합니다. GitHub에서는 Releases에 등록된 설치 파일을 받으면 됩니다.
2. 설치 후 시작 메뉴에서 **YouTube to MP3**를 실행합니다.
3. 유튜브 주소를 붙여넣고 **한 곡** 또는 **재생목록 전체**를 선택합니다.
4. 저장 폴더를 확인하고 **MP3 다운로드**를 누릅니다.

**고객이 받아야 하는 파일은 설치 EXE 하나입니다.** Python·FFmpeg·다운로드 도구가 포함되어 있어 별도로 설치하거나 CMD를 실행할 필요가 없습니다. 고객 PC에 설치된 Python을 사용하지 않으므로 Python 설치 여부나 버전에 의존하지 않습니다. 관리자 권한 없이 현재 Windows 사용자 계정에 설치합니다.

지원 대상은 **64비트 Windows**이며, 유튜브 다운로드와 도구 업데이트에는 인터넷 연결이 필요합니다. 설치 EXE는 약 **105MB**로, 실행 환경과 다운로드·변환 도구를 함께 포함한 크기입니다.

## 저장 파일과 음질

- 기본 저장 위치는 현재 사용자 홈 폴더의 `Downloads`입니다. 예: `C:\Users\사용자이름\Downloads`. 프로그램에서 다른 폴더로 변경할 수 있습니다.
- 한 곡 모드는 주소에 재생목록 정보가 있어도 해당 영상만 저장합니다. 재생목록 전체 모드는 재생목록 이름의 하위 폴더에 순번을 붙여 저장합니다.
- 이용 가능한 최고 품질의 원본 오디오를 **MP3 320kbps**로 변환합니다. 원본 이상의 음질로 복원되지는 않습니다.
- 유튜브 썸네일을 표지로 넣고, 제공되는 제목·음악가·앨범 정보를 태그로 저장합니다. 원본에 없는 정보는 비어 있을 수 있습니다.
- 같은 저장 폴더에 동일한 파일이 있으면 다운로드와 재인코딩을 건너뛰고 표지·태그를 갱신합니다. 파일을 사용 중이라는 오류가 나면 음악 재생 프로그램을 닫고 다시 시도하세요.
- 중지해도 완료된 MP3는 유지됩니다. 미완료 임시 파일은 남을 수 있습니다.

## 업데이트와 제거

- 유튜브 변경으로 다운로드가 실패하면 프로그램의 **다운로드 도구 업데이트**를 실행한 뒤 다시 시도하세요. 비공개·지역 제한 등 접근할 수 없는 영상은 다운로드되지 않을 수 있습니다.
- Windows의 **설치된 앱** 목록에서 제거할 수 있습니다. 다운로드한 음악은 설치 폴더와 별도로 저장되며 제거 대상에 포함되지 않습니다.
